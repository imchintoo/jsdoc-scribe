3. Signal worth writing about today

TypeScript 7.0 shipped stable on 2026-07-08 with no Compiler API — and jsdoc-scribe's own <7.0.0 pin is the reason why

This is the strongest signal found today, and it's an internal one as much as an external one: the backlog item speculatively titled "TypeScript 'Project Corsa' native compiler" in the 2026-08-07 report has now actually shipped as stable TypeScript 7.0, and the specific detail that matters for this project isn't the 10x speed number everyone is writing about — it's that TS7.0 ships with no JS-accessible programmatic Compiler API at all. That API is what jsdoc-scribe's AST-based parsing runs on (TypeScript compiler API used purely as a parser, per the project's own stated architecture). This is exactly why package.json already pins typescript: ">=5.0.0 <7.0.0" — a constraint that existed before today's research but has never been explained publicly. TypeDoc, typescript-eslint, and the Vue/Svelte/Astro/Angular template-checking tooling are all confirmed hitting the identical wall, per their own maintainers, and are explicitly targeting TS 7.1 (where the API is expected to land) rather than 7.0.

This is unused ground on the blog: no prior post has explained the <7.0.0 pin, and it is now genuinely timely (TS7 is one month old, stable, and actively being adopted) rather than speculative. It's also a fact-checkable, low-risk technical piece — no invented numbers, directly grounded in jsdoc-scribe's own manifest file plus Microsoft's own announcement and TypeDoc's own public GitHub issues.
