3. Signal worth writing about today

"Shadow AI" now has hard 2026 numbers behind it, and source code is the single most-leaked data type

Multiple independent 2026 sources converge on the same shape of finding: more than 59% of security leaders confirm or suspect employees are using AI tools their IT/security org never approved; Verizon's 2026 Data Breach Investigations Report puts regular corporate-device AI use at 45% of employees, up from just 15% the year before; and across the shadow-AI research generally, source code is called out as the data type employees hand to unsanctioned GenAI tools most often — ahead of images or other structured data. The 2023 Samsung incident (engineers pasted proprietary firmware source into ChatGPT to debug it; the company banned the tool weeks later after snippets surfaced in public GitHub gists) is still the most-cited concrete case study, which itself says something about how little has changed at the tooling level since then.

This is a different angle from the due-diligence and procurement-questionnaire posts already published (2026-07-23, 2026-07-29) — those covered the buyer-side moment where "where does our code go" gets asked. This angle is the seller/internal-security-review side: what a security team actually finds when it goes looking for shadow AI usage inside its own engineering org, and why a tool that is AST-based and never calls a model can't appear in that finding by construction, not by policy.
