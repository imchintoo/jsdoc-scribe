3. Signal worth writing about today

"Context rot" now has a name, a paper, and a measured performance cost — and it's about internal docs, not just AI trust in general

Two 2026 papers give this angle real teeth. First, Context Rot in AI-Assisted Software Development (arXiv:2606.09090) names and formalizes the failure mode directly: teams increasingly hand AI coding agents persistent context via CLAUDE.md, AGENTS.md, and .cursorrules files describing code structure and conventions — and as the underlying code changes, that context goes stale silently. No error, no warning: the model just starts referencing functions that no longer exist or importing modules that were deleted, and the failure looks like a bad suggestion rather than a documentation bug.

Second, On the Impact of AGENTS.md Files on the Efficiency of AI Coding Agents (arXiv:2601.20404) puts a number on the flip side: across 124 pull requests in 10 repositories, the presence of an AGENTS.md file was associated with a 28.64% lower median runtime and 16.58% fewer output tokens for the AI agent, with comparable task completion — i.e., accurate context isn't just a correctness nicety, it's measurably cheaper to run agents against.

Layered on top: the 2026 Stack Overflow Developer Survey (49,000 respondents, 177 countries) puts AI coding tool adoption at a record 84% while developer trust in AI output accuracy has fallen to 29%, down from 40% in 2024 — and separately, 96% of developers say they don't fully trust that AI-generated code is functionally correct, with 71% never merging AI output without manual review.
